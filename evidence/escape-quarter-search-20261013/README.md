## 流程与转向独立性

第一次被攻击 → STOP 确认 → 等触碰松开 → 扫描找猫 → 停稳并用新画面复核猫 → 选择探索/装死/逃跑。原有找猫、概率、后续轮数和正常跑完后追逐观察流程保留。

选中逃跑后：

ESCAPE_DIRECTION → STOP 确认 → ESCAPE_SIDE_SETTLE → ESCAPE_SIDE_CHECK → ROTATE ±90° → STOP 确认 → ESCAPE_FRONT_SETTLE → ESCAPE_FRONT_CHECK。

- 转前只依据待转侧的超声波；当前前向 BLOCKED、INVALID、过期或未标定均不参与是否允许旋转的判断。不会因当前前方站着猫而拒绝进入侧距搜索。
- 转前要求新的编码器样本、零 RPM、静止窗口，再等待晚于侧距检查起点的有效超声波样本。
- 测距必须严格大于 max(escapeTurnClearanceCm, Uno 对应侧本地安全阈值)。等于阈值不通过；负值、无回波、旧样本不代表空旷。
- 初次优先采用已有方向符号；通常为右侧。初次优先侧不通过而另一侧有效且通过时，可以选另一侧。源码约定右侧 → ROTATE +90，左侧 → ROTATE -90；实际接线与朝向需用户核对。
- 选定旋转方向后沿同一方向搜索，最多 3 次 90°（3 个替代朝向），避免转满一圈反复访问原方向。下一侧不通过或不能获得有效数据就退出，不反复左右摇摆，也不自动前移探路。
- 转后必须新帧序号、采集时间晚于请求、匹配 generation/step 的 FLOOR 结果；CLEAR 才进入 ESCAPE_DRIVE → ESCAPE_MOVE。BLOCKED 则先停车重新进入侧距门控、下一次 90°；INVALID、超时、过期或未标定结束本轮互动。
- 侧距检查、旋转、转后观察和直线逃离持续选择 FLOOR 模式。普通前向开关不能关闭逃离阶段的前向保护；旋转时不会根据前向 BLOCKED 拒绝转身，转身许可由侧距门控及 Uno 本地保护负责。
- 直线逃跑使用一次连续 DRIVE，不周期性停车检查。遇到新 BLOCKED 先 STOP/停稳，再使用剩余搜索次数改向；保留同轮目标距离及依据已收到编码器回报估算的剩余距离，不重新抽取距离。剩余距离包含测距、停车余量等实测误差，尚未验收。
- 直跑期间视觉 INVALID、过期或标定失效立即结束互动并请求 STOP。旋转中侧距过期/无效或触碰中断也停车退出；不按不确定朝向恢复旋转。直跑被触碰中断后，松开需重新停稳并获取新前向画面才续跑剩余距离。

## 参数和回读

网页“猫互动配置”新增“逃离转向侧净空阈值（厘米，必须超过）”，键 escapeTurnClearanceCm，默认 15 cm，范围 1–100 cm。默认值只是初始配置，不是已经测定的旋转安全距离。

先停车保存。界面以板上配置回读显示实际值，并报告 CONFIG_ERROR；该字段随现有猫互动配置保存。旧配置启动时通过默认值覆盖获得该字段。真实保存后重启保留仍需台架核对，离线验证不能代替 NVS 实机确认。

状态显示方向搜索次数、阈值和侧距/转后检查阶段。关键日志：ESCAPE_SIDE_GATE（侧别、距离、有效阈值、次数）、ESCAPE_FRONT_GATE（结果、次数、帧号）、INTERACTION_EXIT（退出原因）。

## 用户台架检查（尚未执行）

1. 读取版本及停车状态，确认右侧超声波对应右转、左侧对应左转；核对每次 ROTATE 命令为 ±90° 与实际方向/角度。不能仅看串口命令就认为物理角度正确。
2. 完成地面标定。触发一次攻击并松开，确认先找猫、复核，再进入逃跑分支；可在停车后暂设装死/探索概率为 0，测试后恢复原值。
3. 用挡板分别形成超过/低于阈值的侧距，观察 ESCAPE_SIDE_GATE；修改阈值后确认板上回读，再重启读取。侧距未通过时不能发起该侧旋转。
4. 当前朝向的前方阻挡不能阻止侧距通过后的旋转。转后新前方 CLEAR 才能发 DRIVE；转后仍 BLOCKED 时，每个下一次 90° 都要重新通过侧距门控。最多 3 次后结束，不无限转。
5. 直线逃跑保持连续；用障碍触发停车后，核对下一次搜索预算和剩余距离。画面无效/过期、未标定或侧向测距不可用时，核对 STOP 和退出原因。
6. 触碰中断旋转必须停车退出；触碰中断直跑必须先等待松开，再停稳、新画面复查后续跑。结束本轮逃跑后，核对原有轮数/装死/重新找猫流程。

台架通过仍不能证明落地高速避障可靠：待补实测旋转扫掠、左右传感器覆盖、视觉延迟、实际车速、停车距离和同色障碍表现。后续速度/距离应按这些数据调整。
