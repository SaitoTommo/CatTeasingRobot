# Uno D1/TX → D0/RX 回环

这是独立的临时诊断固件，57600 / 8N1，不操作电机、传感器或 ESP32。

1. 断开 Uno D0、D1 与 ESP / 电平转换模块的所有信号线。上传时 D0、D1 也不要短接；关闭串口监视器再上传。
2. 上传完成后，用一根线将 Uno 本体 D1/TX 与 D0/RX 直接短接，不经过转换模块。
3. 串口监视器设为 57600。无需输入文字。每两秒发送一个 `LB_TEST:<编号>:0123456789:AbCdEf`，500ms 内收到完全相同的文本就输出 `LOOPBACK_OK id=... passed=... failed=...`，没有收到则输出 `LOOPBACK_TIMEOUT`。
4. 每次成功，板载 L 灯切换亮灭。结果行不会被重新回传，避免无限回声。USB 监视器显示 LB_TEST 本身仅说明 Uno 发出测试包，不表示接收成功；以 LOOPBACK_OK 为准。

打开监视器可能通过 DTR 复位，出现一次 READY 是正常现象。测试中反复出现 READY，或编号/统计归零，才提示再次启动。

Uno 的 USB 串口桥仍与 D0 相连。因此成功证明本次供电与连接条件下 TX/RX 可正常回环；失败不能单独断定 ATmega328P RX 损坏，还需要排除跳线接触、供电和 USB 桥驱动冲突。可以改用稳定的外部 USB 电源，凭板载 L 灯观察是否每两秒翻转；无法显示串口日志时不能据灯不亮确定具体故障点。

测试后移除 D0-D1 短接线，再恢复其他信号线；上传其他固件前同样先移除短接线。
