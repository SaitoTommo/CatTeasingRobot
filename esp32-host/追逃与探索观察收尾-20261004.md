# ESP 0.23：追逃、装死和探索的观察收尾

2026-10-04。按用户最新补充：保留装死，装死结束后重新找猫；后端尚无接口，本轮先不接入后端。

## 实际控制流程

- 逃跑直行结束，仍按原有概率/轮数选择是否装死；没有装死则重新扫描猫。
- 装死等待结束，或装死期间确认猫远离/未出现，不再直接结束互动，而是重新扫描猫。
- 扫描找到猫后，用有效新帧判断猫框中心，小角度转向、停车、停稳、再识别，直至对齐。对齐后进行原地复核；复核期间猫又偏离时重新对齐。找猫或对齐失败则退出，原先从巡游进入的互动恢复保存路线。
- 找到并复核后进入 WAIT_CHASE，网页显示“面向猫观察，等待互动”。持续CAT识别；有效的新识别结果显示猫离开画面则退出。无效/过期输入记作观测不可用，不当作猫离开。
- 等待超时退出。再次触碰或视觉远→近追击时，逃跑分支等待松开后直接转向、逃跑，不再插入旧OBSERVE/FOLLOW_WAIT间隔；探索分支继续声光探索。
- 探索的SIGNAL/OBSERVE/FOLLOW_WAIT阶段，在没有持续按住按钮且无新触碰达到等待时间时重新扫描、对齐猫，然后进入同一个观察窗口。
- 触碰互动不再用“猫框较小、远离”自动直接退出普通观察/复核；画面内的远猫不等于离开画面。
- 原地复核的定时等待期间启用连续CAT识别；停稳/转向期间仍只在停车后请求新帧用于动作决策。

## 设置

猫互动配置新增 `catInteractionIdleSeconds`（探索无互动后重新找猫，默认12秒）和 `catObserveTimeoutSeconds`（找到猫后观察等待上限，默认10秒），范围1–120秒。观察等待值从旧 `postEscapeWaitSeconds` 迁移，旧键保留兼容但不再用于动作。随机逃跑距离、装死概率、轮数和其他设置保留。

这里的“无互动”依据触碰事件计时；视觉远→近判定在观察等待窗口中用于恢复互动。图像内的猫没有被识别为情绪或“攻击”，触碰/靠近只是互动触发证据。
