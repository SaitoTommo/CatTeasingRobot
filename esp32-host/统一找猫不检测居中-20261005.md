# 2026-10-05 统一找猫：检测到猫即可，不检测居中

用户要求主动找猫与被猫触发共用找猫实现，并取消居中检测。修改前的源码、网页、模拟器与文档已提交为 42b0cbd（ESP 0.34 基线）；原始未跟踪采集文件仍保留在本地。

ESP 0.35_UNIFIED_CAT_SEARCH 将所有 CAT 扫描成功统一转入 confirmCat：STOP 确认 → 两次新的编码器样本、零转速、最小等待与安静时间 → catConfirmWaitSeconds → 等待结束后的新 CAT 帧。复核有猫便分发 CHOOSE_TOUCH、CHOOSE_ROBOT、WAIT_CHASE 或原定后续行为，不读取 centerX、不使用猫居中容差，不下发 ALIGN_CAT 转向。主动行为选择复用这一张确认帧，不再次停车复核。复核暂时失去猫时按既有剩余扫描预算重试；无效帧、超时、触碰抢占与通信保护保留。

CAT_CONFIRM 最终请求帧时直接保持 CAT_CONFIRM，不再产生 CAT_CHECK → CAT_CONFIRM 的瞬间日志切换。主动接近/试探短段结束后的 SETTLE → CAT_CHECK 是运动后的实际停稳检查，仍保留；扫描寻找方向、逃跑转向与标签对准也仍保留。这些不再用于把猫框对到画面中央。

兼容：保存的 centerTolerancePercent、alignPwm、alignTimeoutMs 保留并标记 unsupportedSettings，不影响其他保存值；猫居中控件禁用并解释已停用，角度换算仅用于标签。猫远近框宽阈值、主动接近距离与概率、触碰互动分支、标签路线与对准不变。主动接近依照当前车头方向执行，不先把猫框转到中央。
