全部策略与几何参数
catNearWidth、catFarWidth、tagStopWidth 是归一化框宽，需现场标定；frontCalibrated 默认 false，不能把视频显示成功当作避障已有效。scanStepPulses 是每步编码器脉冲；scanMinimumMs/scanQuietMs 控制停稳等待；scanVisionTimeoutMs 是单次新帧等待上限。catApproachStepCm 为慢接近分段上限；厘米猫距离 farCatThresholdCm/catLeaveDistanceCm 及旧 searchTimeoutMs/finalSearchTimeoutMs 不用于当前 ESP 控制，请用宽度和新扫描参数。改变 floorRoiTop 后地面参考失效，必须重新采集。

Uno 接收与发送调试
真实 UART：D6/GPIO43 → 电平转换 → Uno D12 软件接收；Uno D1/TX → 电平转换 → D7/GPIO44，共地，57600 波特。发送成功只表示命令入队，执行结果请查看 AK / DONE / ERROR 和传感器回报。
Uno V5.9 诊断：默认每秒简短心跳；详细模式增加命令进入/退出及遥测分段标记。日志中的 EVENT DIAG S 后为十进制步骤和命令编号；H 心跳字段为十六进制，含计时、循环数、最大循环毫秒、遥测编号、分段、等待位、RX 溢出、丢弃命令数。
