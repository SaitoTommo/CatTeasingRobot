# ESP 0.22：每轮随机逃跑距离

用户要求仍以距离结束，每轮在最小和最大距离之间随机取值，不改成5秒或10秒定时运动。

- 网页“猫互动配置”新增逃跑最小距离、逃跑最大距离，单位厘米，范围1–100，最小值不得大于最大值。
- ESP 每轮准备直行且前方条件通过后抽取一次目标，均匀映射到区间，直接用于 `DRIVE` 命令，不再扣除 `stopMarginCm`。
- 相同最小/最大值表示固定距离；实际轮距仍由编码器脉冲量化，轮子空转不能代表机身位移。
- 触碰打断时保存剩余距离，松开后续跑，不重新抽取；停止与既有避障条件继续有效。
- `patrolStatus.escapeTargetCm` 和网页显示本轮目标距离，`ESCAPE_DISTANCE` 日志记录抽取值。
- 启动时旧配置没有范围字段，则将旧 `escapeDistanceCm-stopMarginCm`（至少1厘米）迁移为相等的最小/最大值。原26/3迁移为23/23；已有概率与其他配置保留。旧固定距离字段从通用网页编辑区隐藏。
- 原有“每轮逃跑后装死概率”和“逃跑最多完成轮数”仍然独立生效。

验证：实际策略核心745检查通过，设置/PWM2632检查通过，扫描259、连续互动245及视觉门控/CRC检查通过；网页21测试通过。新增覆盖随机区间端点/中间值、固定距离、50厘米DRIVE命令、暂停续跑不重抽、范围校验、网页保存与目标显示。完整ESP编译Flash3735354/8257536，静态RAM78936/327680字节。尚未进行实机行进距离验收。
