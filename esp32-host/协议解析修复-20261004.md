# ESP 0.21 协议解析修复

2026-10-04。依据 `D:/data/download/esp32-log(23).json` 及当前 ESP/Uno 源码检查；本记录不是实机运动验收。

## 已确认的故障

配置回读 `catConfirmPreyPercent=0`、`catConfirmExplorePercent=0`。217304 ms 原地复核成功，217305 ms 进入 ESCAPE_DIRECTION，217307 ms 因 `escape side observation expired` 退出。

215840 ms 左侧回报 `DATA 458 HW SL 1 1 0 11.6 11.6 P`，215841 ms 右侧回报 `DATA 458 HW SR 1 1 0 -1.0 -1.0 P`。ESP 策略侧距离解析格式只有8个转换项，却检查 sscanf 返回9，导致 side/sideAt 永远不更新。界面遥测正常不代表策略已收到数据。

## 修改

- 修复侧距离解析返回值为8。接收合法有限距离（包括 -1），拒绝 NaN、超范围和额外字段。
- 按用户明确规则，-1 无回波允许转向；未收到数据或超过2500 ms未更新仍按过期处理。
- MS/MP/MD、MA、AK/ACK、ERROR 不再接受额外字段。
- 编码器回报拒绝非有限/负RPM及额外字段。
- 触碰回报只接受 TOP/LEFT/RIGHT/REAR，以及0/1按下状态；未知区域不再默认为TOP。
- 启动停车、几何设置、会话启动/结束和配置读取检查匹配的完成内容，不能只凭相同命令编号继续。保留 Uno GET_CONFIG 的无后缀 DONE，以及模拟器 CONFIG 后缀兼容。
- 检查 Uno 参数数目、类型及范围解析、ESP compact TB分块与结束检查、VQ/SD扫描识别和灯光事件解析；未发现第二处同样的转换数量错误。此次不修改 Uno 固件。
